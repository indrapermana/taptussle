# TapTussle Game-Specific Sound Pack v2

This add-on complements the 20-effect shared pack.

All files are WAV / mono / 16-bit PCM / 44.1 kHz.

Important: the current M16 Slither-style Snakes design omits a speed-boost mechanic.
`snake_boost.wav` is included only as a future-ready asset and should not be wired
into M16 unless the gameplay plan changes later.

All effects were synthesized specifically for TapTussle. No third-party samples.
